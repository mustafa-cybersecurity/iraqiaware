# IraqiAware – برنامج الوعي بالأمان السيبراني
## مدعوم بالذكاء الاصطناعي

---

## نظرة عامة

**IraqiAware** هو تطبيق سطح مكتب لنظام Windows يراقب شاشتك باستمرار بحثاً عن التهديدات الأمنية السيبرانية باستخدام نماذج رؤية الذكاء الاصطناعي.

### المميزات الرئيسية

- 🔍 **مراقبة تلقائية للشاشة** – التقاط لقطة شاشة كل 5 ثواني (قابل للتكوين)
- 🤖 **تحليل بالذكاء الاصطناعي** – إرسال لقطات الشاشة إلى OpenAI GPT-4 Vision أو Google Cloud Vision للتحليل
- 🚨 **كشف التهديدات في الوقت الفعلي** – كشف كلمات المرور الضعيفة، ومواقع التصيد الاحتيالي، والبيانات الحساسة المكشوفة، والتصفح غير الآمن
- 🌙 **واجهة Dark Theme** – واجهة مستخدم حديثة وعصرية
- 🌐 **ثنائي اللغة** – دعم كامل للغة الإنجليزية والعربية (RTL)
- 📊 **لوحة تحكم** – حالة المراقبة المباشرة، عدد التهديدات، سجل النشاط
- ⚙️ **لوحة الإعدادات** – تكوين مزود الذكاء الاصطناعي، مفتاح API، اللغة، وتكرار الالتقاط
- 🔔 **إشعارات شريط النظام** – تنبيهات Windows Balloon للتهديدات المكتشفة
- 📁 **تصدير** – تصدير سجل التنبيهات بصيغة JSON أو CSV

## تعليمات البناء

### 1. تثبيت المتطلبات الأساسية

```powershell
# تثبيت vcpkg (إذا لم يكن مثبتاً)
git clone https://github.com/microsoft/vcpkg.git C:\vcpkg
C:\vcpkg\bootstrap-vcpkg.bat
setx VCPKG_ROOT C:\vcpkg

# تثبيت Qt 6 عبر Qt Online Installer (https://www.qt.io/download)
# اختر: Qt 6.x → MSVC 2022 64-bit
```

### 2. الاستنساخ والبناء

```powershell
git clone https://github.com/mustafa-cybersecurity/iraqiaware.git
cd iraqiaware

mkdir build
cd build

# التكوين (Release x64)
cmake -G "Visual Studio 17 2022" -A x64 `
      -DCMAKE_BUILD_TYPE=Release `
      -DCMAKE_TOOLCHAIN_FILE="$env:VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake" `
      ..

# البناء
cmake --build . --config Release --parallel
```

### 3. التشغيل

```powershell
.\build\x64\Release\iraqiaware.exe
```

### 4. بناء ملف Windows x64 EXE عبر GitHub Actions

يحتوي المستودع على سير عمل في المسار `.github/workflows/build-windows-x64.yml` لبناء نسخة **Release x64** على `windows-latest` ورفع Artifact باسم `iraqiaware-windows-x64`.

يمكنك تشغيله من **Actions → Build Windows x64 EXE → Run workflow** ثم تنزيل الـ Artifact من نتيجة التنفيذ.

| الحقل | الوصف |
|---|---|

## التقنيات المستخدمة

- **C++17** – معيار C++ الحديث
- **Qt 6** – إطار واجهة مستخدم متعدد المنصات (Dark Theme)
- **cURL** – عميل HTTP لطلبات AI API
- **nlohmann/json** – تحليل JSON
- **spdlog** – سجل ملفات دوار سريع
- **GDI+** (Windows) – التقاط لقطات الشاشة
- **OpenSSL** – TLS للاتصالات الآمنة بـ API
